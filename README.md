# FaceCheck – Control de asistencia

Interfaz web para que los trabajadores de una empresa registren su **entrada** y **salida** con su DNI y verificación facial. Se adapta a celular, tablet y PC.

## Cómo funciona

1. El trabajador escribe su DNI.
2. Elige **Entrada** o **Salida**.
3. El sistema muestra sus datos y verifica su rostro.
4. Aparece la confirmación con la hora del registro.

## Tecnologías

- HTML5
- CSS3 (Flexbox y diseño responsive)
- JavaScript
